# TrimUI Uploader

Утилита для загрузки ROM-файлов и обложек на портативную консоль TrimUI Smart Pro S через SSH.

## Возможности

### Загрузка на консоль

- Загрузка игр (ROM) в выбранную директорию (предустановленные системы или свой путь через Custom).
- Поддержка PortMaster: файлы портов заливаются в `Data/ports/<имя_игры>`, обложки — в `Imgs/PORTS` с именем, совпадающим с `.sh`-скриптом.
- Автоматическая загрузка обложек в соответствующую папку `Imgs`.
- **Привязка картинок к играм по порядку**: первая добавленная картинка → к первой игре, вторая → ко второй и т. д. Если картинок больше, чем игр, лишние получают имя последней игры с суффиксом `_1`, `_2` и т. д.
- Автопереименование картинок по имени подпапки (для PORTS) или имени игры (для остальных систем).
- **Управление регистром имён файлов**: опции «Нижний регистр» и «Верхний регистр» — применяются к именам файлов, расширениям и именам папок при загрузке.
- **Сохранение структуры папок**: при добавлении папки с файлами можно выбрать, переносить ли саму папку целиком (флаг включён) или только её содержимое с вложенными подпапками (флаг выключен).
- Прогресс-бар: процент от общего веса всех выбранных файлов.
- Логирование с кнопкой «Скопировать логи» для диагностики.
- Сохранение настроек подключения между запусками.
- Кнопка проверки соединения и автоопределение пути к папке ROMs.
- Кроссплатформенность: Windows, Linux, macOS.

### Просмотр ROM-ов на консоли

- Сканирование всех папок с играми по SSH, отображение списка с фильтрами по платформе и поиском по названию.
- Карточка выбранной игры: обложка, платформа, имя файла, формат, размер, полный путь, дата изменения, контрольная сумма MD5.
- Скачивание отдельного ROM-файла или обложки на ПК.
- Скачивание ПАК-архива: игра + обложка в отдельную папку.
- Замена обложки прямо из приложения (с автоматической конвертацией в PNG при необходимости).
- Копирование пути к файлу в буфер обмена.
- Прогресс-бар при скачивании с отображением процентов.
- Для портов (PORTS) скачивание игры и ПАК-архива отключено — порты нельзя скачать одним файлом.
- **Удаление ROM-файлов**: удаляет выбранный файл игры и связанную обложку с подтверждением. Для портов (PORTS) удаление отключено — у них другая структура файлов.


## Требования

- Python 3.8 или выше.
- Библиотеки `paramiko` и `Pillow` (см. `requirements.txt`).

## Установка и запуск

Установи зависимости и запусти приложение:

    pip install -r requirements.txt
    python trimui_uploader.py

Или:

1. Скачайте архив `TrimUI_Uploader_v1.0.0.zip` из раздела Releases.
2. Распакуйте в любую удобную папку (не в `Program Files`).
3. Запустите `TrimUI_Uploader.exe`.

> ⚠️ **Примечание про антивирусы.** Сборки через PyInstaller могут блокироваться антивирусами как подозрительные — это ложное срабатывание. Если антивирус ругается, проверьте файл на VirusTotal или добавьте папку в исключения.

## Использование

### Загрузка игр

1. Предварительно включи SSH на самой консоли: *Система → Разработчик → Включить SSH*.
2. Введи IP‑адрес консоли (посмотреть в настройках: *Система → Информация об устройстве → WI‑FI: цифры до `[]`*), логин (по умолчанию: `root`) и пароль (по умолчанию: пусто) — это данные для SSH‑подключения.
3. Выбери систему из списка или укажи `Custom` и впиши путь вручную. Если не знаешь путь — нажми «🔍 Найти путь», и программа определит его автоматически.
4. Добавь файлы игр (кнопки «Добавить файлы» или «Добавить папку»).
   - **«Сохранить структуру папок»** — если включено, выбранная папка переносится целиком (с её именем). Если выключено — переносится только содержимое, но вложенные подпапки сохраняются.
   - **«Нижний регистр» / «Верхний регистр»** — преобразуют имена загружаемых файлов (и папок) в выбранный регистр.
5. Добавь обложки (кнопка «Добавить картинки»). Картинки привязываются к играм по порядку добавления: первая картинка — к первой игре, вторая — ко второй и т. д. Если картинок больше, чем игр, лишние получат имя последней игры с суффиксом `_1`, `_2` и т. д.
6. Нажми «Залить на консоль».
7. После завершения обнови список ROMs на самой консоли.

> ⚠️ **Важно:** предустановленные пути рассчитаны на SD Base на основе стока и CrossMix (от пользователя Spectrumist, с точкой монтирования `/mnt/sdcard/mmcblk1p1`). Если у вас другая прошивка или структура папок — нажмите «🔍 Найти путь» (нужен включённый SSH) или выберите `Custom` и укажите путь вручную.

### Просмотр и скачивание ROM-ов

1. Нажми «📂 Посмотреть ROM-ы» — откроется отдельное окно.
2. Приложение подключится к консоли и просканирует все папки с играми.
3. Слева появится список: название, платформа, размер. Используй фильтр по платформе и строку поиска сверху.
4. При выборе игры справа отображается карточка с обложкой и информацией (путь, дата изменения, MD5 и т. д.).
5. Доступные действия:
   - **📋 Копировать путь** — копирует полный путь к файлу на консоли в буфер обмена.
   - **📂 Скачать на ПК** — скачивает выбранный ROM-файл. Путь сохранения выбираешь в диалоге. Прогресс отображается в строке состояния и на прогресс-баре.
   - **📦 Скачать ПАК** — скачивает игру и обложку в отдельную папку вида `Платформа - Название игры`. Папку назначения выбираешь в диалоге.
   - **🖼 Изменить обложку** — загружает выбранную на ПК картинку на консоль в качестве обложки. Если файл не PNG — автоматически конвертируется.
   - **💾 Скачать обложку** — скачивает обложку выбранной игры на ПК.
   - **🗑 Удалить ROM** — удаляет выбранный файл игры и его обложку с консоли. Требует подтверждения. Для портов (PORTS) кнопка отключена.
6. Кнопка «🔄 Обновить» — повторно сканирует консоль (полезно после загрузки новых файлов).

> ⚠️ **Для портов (PORTS)** кнопки «Скачать на ПК» и «Скачать ПАК» отключены: порты — это не отдельные файлы, а наборы скриптов и данных, их нельзя скачать одним файлом. Обложки для портов доступны: можно менять и скачивать.

## Выбор системы

### Предустановленные системы (GBA, PS, NDS и т. д.)

- В поле «Путь» автоматически подставляется путь к нужной папке, например `/mnt/sdcard/mmcblk1p1/Roms/GBA`.
- Файлы игр заливаются прямо в эту папку.
- Обложки заливаются в `Imgs/<система>` (например, `Imgs/GBA`).
- Имя картинки берётся из имени файла игры (например, `Pokemon.gba` → `Pokemon.png`). При загрузке нескольких игр картинки сопоставляются по порядку добавления. Если картинок больше, чем игр, лишние получают суффикс `_1`, `_2` и т. д.
- Поле «Подпапка» скрыто.

### PORTS (порты PortMaster)

При выборе PORTS в интерфейсе появляется дополнительное поле «Подпапка».

- **Поле «Путь»** — укажите корень раздела (точку монтирования), где лежат папки `Roms`, `Imgs`, `Data`. Например: `/mnt/sdcard/mmcblk1p1`. Не указывайте путь до `Data/ports` — он добавится автоматически.
- **Поле «Подпапка»** — введите имя игры (например, `MyGame`). Это имя используется:
  - Для создания папки с файлами игры: `<путь>/Data/ports/MyGame/`.
  - Для переименования картинок: обложки будут называться `MyGame.png`, `MyGame.jpg` и т. д. — это имя должно совпадать с именем `.sh`-скрипта, который PortMaster создаёт на консоли при установке порта.
- **`.sh`-скрипт загружать через приложение не нужно** — он создаётся самим PortMaster на консоли.
- Обложки заливаются в `<путь>/Imgs/PORTS/`.

**Пример:**

1. Путь: `/mnt/sdcard/mmcblk1p1`
2. Подпапка: `Vampire_Survivors`
3. Файлы игры → `/mnt/sdcard/mmcblk1p1/Data/ports/Vampire_Survivors/`
4. Картинки → `/mnt/sdcard/mmcblk1p1/Imgs/PORTS/Vampire_Survivors.png`

### Custom (свой путь)

При выборе Custom поле «Путь» очищается, а под полем «Система» появляются дополнительные поля: «Имя системы» и кнопка «💾 Сохранить».

- В поле «Путь» введите полный путь к папке с играми (например, `/mnt/sdcard/mmcblk1p1/Roms/AtariJaguar`).
- Файлы игр заливаются прямо в указанную папку. Если её не существует — она создаётся автоматически.
- Обложки заливаются в `Imgs/<последняя_часть_пути>`. Например, для пути `/mnt/sdcard/mmcblk1p1/Roms/AtariJaguar` обложки пойдут в `Imgs/AtariJaguar`.
- Имя картинки берётся из имени файла игры.

**Сохранение своей системы:**

Чтобы не вводить путь каждый раз, сохраните его как новую систему:

1. В поле «Имя системы» введите название (например, `Atari Jaguar`).
2. В поле «Путь» укажите полный путь к папке с играми.
3. Нажмите «💾 Сохранить» — система появится в выпадающем списке и будет доступна при следующем запуске.

## Как найти путь к ROMs вручную

Если автоопределение не сработало, путь можно найти самому:

1. Подключись к консоли по SSH.
2. Выполни команду:

       find /mnt -maxdepth 4 -name "Roms" -type d 2>/dev/null

3. В ответе появится путь, например `/mnt/sdcard/mmcblk1p1/Roms`.
4. Выбери в приложении `Custom` и впиши этот путь.

## Сборка .exe для Windows

Установи PyInstaller и собери проект:

    pip install pyinstaller
    pyinstaller --noconsole --onefile --name TrimUI_Uploader trimui_uploader.py

Готовый файл появится в папке `dist`.
